CORE ALGORITHMIC FOUNDATION

Queuing & Priority Data Structures

Three specialized data structures handling standard FIFO arrivals, emergency low-battery prioritization via Min-Heap, and VIP/fast-track access via Double-Ended Deque.

DATA STRUCTURE 1

Standard FIFO Queue

O(1) Enqueue / Dequeue

First-In, First-Out queue for standard EVs with normal battery levels (>25%). Dispatched in chronological order of arrival.

Queue is empty
DATA STRUCTURE 2

Priority Min-Heap (Critical EVs)

O(log n) Heapify

Binary Min-Heap prioritizing urgent EVs (≤25% battery). The vehicle with lowest remaining charge bubbles to the root for instant emergency dispatch.

Binary Tree Visualization (Root = Minimum Battery)
Sequential Array Representation [Index 0..n-1]
DATA STRUCTURE 3

Double-Ended Queue (Deque)

O(1) Both Ends

Double-ended queue for special and VIP dispatch. Allows insertion and removal at both front (priority bypass) and rear.

Deque is empty
GRAPH ALGORITHMS

City Road Network & Dijkstra's Algorithm

Weighted undirected graph modeling urban road network transit costs, combined with Dijkstra's algorithm accelerated by a Min-Heap priority queue to guarantee mathematically optimal routing.

ALGORITHM SPECIFICATION

Dijkstra Shortest Path Formulation

O((V + E) log V)

Graph Structure

Vertices (V): Urban nodes representing intersections and station depots (A, B, C, D, E).

Edges (E): Road connections weighted by physical travel distance and traffic delays.

Priority Queue Relaxation

Maintains tentative distances in a Min-Heap. At each step, extracts the vertex with minimum tentative distance and relaxes all outgoing edges.

Nearest Station Dispatch

Automatically computes shortest paths to all active stations with free bays and assigns the EV to the global minimum cost station.

Queue Enqueue / Dequeue O(1)

Constant time FIFO insertion & removal using circular head/tail indices in array memory.

Space: O(n)
Min-Heap Insert / Extract-Min O(log n)

Binary tree heapify-up and heapify-down bubbling operations bounding height to log2(n).

Space: O(n)
Deque Add / Remove Ends O(1)

Double-ended queue access allowing instant insertion and removal at both front & rear.

Space: O(n)
Dijkstra Shortest Path O((V + E) log V)

Custom Min-Heap priority queue optimization over vertex relaxation on weighted graph.

Space: O(V + E)
